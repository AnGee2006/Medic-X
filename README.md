# Medic X

Medic X is an AI-powered healthcare appointment tracking system designed to improve patient appointment management and reduce missed consultations.

## Features

* Patient and Admin Portals
* Doctor Availability Viewing
* Appointment Rescheduling
* Automated Missed Appointment Alerts
* AI-based Prediction for Missed Appointments
* Centralized Dashboard for Appointment Monitoring

## Technologies Used

* Python
* SQL / Database Management
* HTML, CSS, JavaScript
* AI/ML Concepts
* Oracle / MySQL (if used)

## Project Objective

The project aims to enhance healthcare scheduling efficiency by predicting patient no-shows and enabling proactive appointment management.
